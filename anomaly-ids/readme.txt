CSCI262 Assignment 3 Submission

FILES INCLUDED:

ids.py   - Main Python program (Initial Input + Activity Engine)

Report.pdf     - Design and implementation report

Events.txt     - Initial event definitions

Stats.txt      - Initial statistics

readme.txt     - This file

HOW TO RUN:

Open a terminal or command prompt.

Navigate to the folder containing these files.

Run the command:

python ids.py Events.txt Stats.txt 5

(Note: 5 is the number of baseline days to generate. You can change it to any positive integer.)

OUTPUT:

activity_log.txt – Baseline activity logs generated by the Activity Engine for the specified number of days.

baseline_stats.txt - Generated by the Analysis Engine. Contains calculated baseline means and standard deviations for each event.

live_data.txt - Created when the Alert Engine simulates live activity using user-provided statistics.
